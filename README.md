# SFTool releases

Публичная витрина релизов **SFTool** (Shadow Fight Tool) — собранные и
подписанные APK, автоматически публикуемые из приватного репозитория
[`lharmonie07/myapp`](https://github.com/lharmonie07/myapp).

Здесь нет исходного кода и ключей — только готовые к установке файлы,
доступные по прямой ссылке (это нужно приложению для проверки обновлений:
`GET /repos/lharmonie07/fiduajoidjlasda-lkdsajd/releases/latest` работает
без авторизации, потому что репозиторий публичный).

Скачивать напрямую можно со страницы [Releases](../../releases).
